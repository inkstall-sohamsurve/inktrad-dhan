KEY COMPONENTS EXPLAINED
========================

🎯 main.py
   - FastAPI application initialization
   - CORS middleware configuration
   - Router registration
   - WebSocket endpoint: WS /ws/live-feed
   - Lifespan events (startup/shutdown)
   - Health check endpoint: GET /health

🌟 websocket_manager.py (MOST CRITICAL)
   - ConnectionManager: Manages React client connections
   - DhanWebSocketManager: Manages DHAN WebSocket feed (singleton)
   - Intelligent subscription management
   - Auto-reconnection logic
   - Broadcasting tick data to clients

🔐 security.py
   - Password hashing (Bcrypt)
   - Credential encryption (Fernet)
   - JWT token creation and validation
   - Secure data handling

💾 database.py
   - MongoDB connection with Motor (async)
   - Collection getters
   - Index creation
   - Connection lifecycle management

🔌 dhan_service.py
   - DHAN API client initialization per user
   - All trading operations (orders, positions, funds, etc.)
   - Error handling and logging
   - Credential decryption


MONGODB COLLECTIONS
===================

users
   - _id: ObjectId
   - username: str (unique, indexed)
   - email: str (unique, indexed)
   - hashed_password: str
   - dhan_client_id: str (encrypted)
   - dhan_access_token: str (encrypted)
   - created_at: datetime

watchlists
   - _id: ObjectId
   - user_id: str (indexed)
   - name: str
   - instruments: array of {security_id, symbol, exchange_segment}
   - created_at: datetime
   - updated_at: datetime

orders_log
   - _id: ObjectId
   - user_id: str (indexed)
   - dhan_order_id: str (indexed)
   - symbol: str
   - security_id: str
   - exchange_segment: str
   - transaction_type: str (BUY/SELL)
   - quantity: int
   - price: float
   - trigger_price: float
   - order_type: str
   - product_type: str
   - status: str
   - timestamp: datetime (indexed)


WEBSOCKET DATA FLOW
===================

1. React Client connects to WS /ws/live-feed
2. Client sends: {"action": "subscribe", "instruments": ["1333", "26000"]}
3. ConnectionManager registers client subscription
4. ConnectionManager tells DhanWebSocketManager to subscribe
5. DhanWebSocketManager subscribes to DHAN (if not already subscribed)
6. DHAN sends tick data
7. DhanWebSocketManager receives tick
8. DhanWebSocketManager forwards to ConnectionManager
9. ConnectionManager broadcasts to all subscribed clients
10. React Client receives real-time market data


API ENDPOINTS SUMMARY
=====================

Authentication (No auth required)
   POST /auth/register          - Register new user
   POST /auth/login             - Login and get JWT token

Authentication (Auth required)
   POST /auth/dhan-credentials  - Add/update DHAN credentials
   GET  /auth/me                - Get current user profile

DHAN API (Auth required + DHAN credentials required)
   GET    /api/v2/dhan/profile      - Get trading profile
   GET    /api/v2/dhan/funds        - Get available funds
   GET    /api/v2/dhan/positions    - Get open positions
   GET    /api/v2/dhan/holdings     - Get holdings
   GET    /api/v2/dhan/order-book   - Get order book
   GET    /api/v2/dhan/trade-book   - Get trade book
   POST   /api/v2/dhan/place-order  - Place new order
   PUT    /api/v2/dhan/modify-order - Modify existing order
   DELETE /api/v2/dhan/cancel-order/{order_id} - Cancel order

Watchlist (Auth required)
   POST   /api/v2/watchlist             - Create watchlist
   GET    /api/v2/watchlist             - Get all watchlists
   GET    /api/v2/watchlist/{id}        - Get specific watchlist
   PUT    /api/v2/watchlist/{id}        - Update watchlist
   DELETE /api/v2/watchlist/{id}        - Delete watchlist
   POST   /api/v2/watchlist/{id}/add    - Add instrument
   DELETE /api/v2/watchlist/{id}/remove - Remove instrument

WebSocket
   WS /ws/live-feed - Real-time market data feed

Utility
   GET /              - Root endpoint
   GET /health        - Health check
   GET /docs          - Swagger UI (API documentation)
   GET /redoc         - ReDoc (Alternative API documentation)


QUICK START COMMANDS
====================

Setup:
   python -m venv venv
   venv\Scripts\activate          # Windows
   source venv/bin/activate       # macOS/Linux
   pip install -r requirements.txt
   python setup_env.py            # Generate encryption key
   # Edit .env with your settings

Run Server:
   python run.py
   # OR
   uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

Test API:
   python test_api.py

Docker:
   docker-compose up -d           # Start all services
   docker-compose logs -f         # View logs
   docker-compose down            # Stop all services


ENVIRONMENT VARIABLES (.env)
============================

Required:
   MONGODB_URL                    # MongoDB connection string
   DATABASE_NAME                  # Database name
   JWT_SECRET_KEY                 # Secret key for JWT
   ENCRYPTION_KEY                 # Encryption key (from setup_env.py)
   DHAN_MASTER_CLIENT_ID          # DHAN client ID
   DHAN_MASTER_ACCESS_TOKEN       # DHAN access token

Optional:
   JWT_ALGORITHM                  # Default: HS256
   ACCESS_TOKEN_EXPIRE_MINUTES    # Default: 1440 (24 hours)
   HOST                           # Default: 0.0.0.0
   PORT                           # Default: 8000
   RELOAD                         # Default: False
   CORS_ORIGINS                   # Comma-separated URLs
